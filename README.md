# Homebrew tap for eudi-dev

```sh
brew trust eudi-dev/tap
brew install eudi-dev/tap/eudi-dev
```

Homebrew loads formulas only from trusted taps, so trust this tap once. This installs the `eudi` command with shell completion. The release workflow of [eudi-dev](https://github.com/eudi-dev/eudi-dev) updates the formula for every stable release.
